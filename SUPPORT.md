# Getting Help

Choose the place that best matches what you need:

| Need | Where to go |
| --- | --- |
| A reproducible app bug | [Open a bug report](https://github.com/petty-foss-dev/MemoryManager/issues/new?template=bug_report.yml) |
| A feature proposal | [Open a feature request](https://github.com/petty-foss-dev/MemoryManager/issues/new?template=feature_request.yml) |
| Questions and ideas | [GitHub Discussions](https://github.com/petty-foss-dev/MemoryManager/discussions) |
| Chat with the community | [Discord](https://discord.gg/Hw4nmXRehb) |
| A security vulnerability | Follow [SECURITY.md](SECURITY.md) |

Before posting, remove personal file names, folder paths, and unredacted diagnostic data.
